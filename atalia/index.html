Seguridad del registro

PIN local activado en este navegador, sin cifrado de registros ni control de usuarios centralizado. El PIN es local y no cifra registros. La carga a Dropbox requiere autorización. Atalía V1.0.2 incorpora registros a la Base Maestra vigente con respaldo automático, control de revisión y verificación posterior.

El Dashboard no se modifica. Antes de cada escritura de la Base Maestra, Atalía V1.0.2 crea un respaldo automático en Dropbox y usa control de revisión para impedir sobrescribir cambios ajenos.

Respaldo de emergencia · opcional

Solo si vas a cambiar de teléfono, navegador o archivo de aplicación. La copia contiene registros y fotografías; guárdala de forma privada. No se utiliza para sincronizar ni actualiza la Base Maestra.

Referencia oficial ATALÍA

Carga una sola vez la Base Maestra V30 (.xlsx). La aplicación lee internamente VILLAS, CATÁLOGO, LIBRO DE OBRA y PENDIENTES. Nunca necesitas cargar CATÁLOGO por separado.
