Registro de obra

Preparación para el iPhone del responsable de campo

Aplicativo para iPhone

Esta versión es de preparación. La autenticación personal y la sincronización segura aún no están habilitadas. No utilices esta pantalla para registrar actividades reales.

La aplicación utiliza el teléfono personal sin acceso a fotografías no seleccionadas ni a otras aplicaciones. El propietario conservará el control de los permisos y del registro de obra.

Instalación

Cuando el administrador habilite la versión operativa, abre su dirección en Safari, pulsa Compartir y elige «Añadir a pantalla de inicio». Se instala una sola vez; las siguientes versiones se actualizarán desde el mismo icono.
